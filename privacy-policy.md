# 📝 Política de Privacidade – To Do App Test

### Última atualização: 28 de março de 2025

## 📌 1. Informações Gerais

Este aplicativo, To Do App Test, respeita a privacidade dos usuários. Nenhuma informação pessoal é coletada, armazenada ou compartilhada.

## 🔒 2. Dados Armazenados

O aplicativo salva apenas as tarefas criadas pelo próprio usuário, que são armazenadas localmente no dispositivo. Não há envio de dados para servidores externos.

## 🚀 3. Compartilhamento de Dados

Nenhuma informação é compartilhada com terceiros.

## 🛠 4. Permissões do Aplicativo

O aplicativo não solicita permissões além das necessárias para seu funcionamento.
